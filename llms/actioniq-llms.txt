## What an agent can and cannot reach

- The production API host **https://api.actioniq.com** is live but answers **HTTP 403 Forbidden**
  (AWS API Gateway) on every path anonymously. Access requires credentials issued under an
  enterprise contract.
- The documentation, **https://docs.actioniq.com/actioniq-help-center**, is a GitBook space gated
  by Auth0 visitor authentication. Unauthenticated requests are redirected to
  `login.actioniq.com/authorize` and end on an error page. There is no public API reference.
- **No machine-readable contract is published.** No OpenAPI, Swagger, AsyncAPI, GraphQL SDL,
  Postman collection, `.proto`, MCP server, or A2A agent card was found on any ActionIQ host.
- **No SDK.** Nothing first-party on npm, PyPI, RubyGems, or crates.io. The public GitHub orgs
  (ActionIQ, ActionIQ-OSS) hold only data-infrastructure forks and internal build tooling.
- The Atlassian status page **status.actioniq.com** has been deactivated ("Page Inactive",
  team-members only).

## APIs

- [ActionIQ Profile API](https://www.actioniq.com/blog/actioniq-profile-api/): Real-time access to
  customer identities, attributes, and audience membership within milliseconds. Powers inbound
  decisioning — web personalization, call center support — connecting data-warehouse intelligence
  to customer-experience applications. Documented integrations include Adobe Target and Moveable
  Ink. Base URL `https://api.actioniq.com`.
- [ActionIQ Data Ingestion API](https://www.actioniq.com/library/): Real-time REST endpoint for
  streaming customer event data into the platform. Supports push-based streaming from in-house
  systems for clickstream and behavioral capture, feeding audience segmentation and campaign
  orchestration. Base URL `https://api.actioniq.com`.

Non-API integration paths ActionIQ documents alongside the REST surface: SFTP, Amazon S3 and
Google Cloud Storage file transfer, and JDBC pull-based direct query against the customer's
warehouse.
